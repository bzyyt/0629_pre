# 大模型基础｜一页复习笔记

## 1. 与普通分类模型有什么区别？

LLM（大语言模型）本身也是深度学习模型，通常经过大规模文本预训练。这里比较的是专用分类模型与生成式 LLM；模型规模、网络结构、任务类型是不同维度，不能简单等同。

分类模型：输入 → 特征 → 固定类别概率 → 类别；常用带标签数据训练。
生成式 LLM：上下文 → 下一个 Token 的概率 → 选择 Token → 反复生成；常见预训练任务是预测下一个 Token，之后可通过指令微调等方式适应交互。
两者都用参数、损失函数、反向传播和梯度下降。LLM 每一步也在词表上做概率预测；更可能的文本不一定是事实。

## 2. 八个核心概念

| 概念 | 直观理解与关键边界 |
| --- | --- |
| Token | 文本的处理单位，可为字、词片段、标点等；不固定等于一个汉字或单词。 |
| Embedding | 将 Token ID 映射为可学习的向量；`[B,L] → [B,L,d]`，B 为批量、L 为序列长度、d 为向量维度。 |
| Attention | 按当前内容与其他位置的关联程度，加权汇总信息；生成时通常不能看未来 Token。 |
| Transformer | 组合注意力、前馈网络、残差连接、归一化等的架构，并引入位置信息；许多生成式 LLM 使用其解码器式结构。 |
| Prompt | 给模型的任务、背景、材料、约束和例子；好的提示明确“做什么、依据什么、怎样输出”。 |
| 上下文窗口 | 一次处理能容纳的 Token 范围；输入、历史、输出等占用预算，具体规则依模型而异。长上下文不保证完全记住所有细节。 |
| 温度 T | 调节采样分布：`pᵢ = softmax(zᵢ/T)`（T>0）；低温更集中，高温更分散。降低温度不等于提高事实正确率。 |
| 幻觉 | 生成看似合理、实际上错误或无依据的内容，如编造论文、数字或 API；需要原始资料、检索与实际验证。 |

## 3. 五个任务对比例子

| 场景 | 普通分类模型的任务 | 生成式 LLM 的任务 |
| --- | --- | --- |
| 商品评价 | 判断正面／负面 | 概括优缺点并起草回复 |
| 邮件 | 判断垃圾／正常 | 总结邮件并提取待办事项 |
| 新闻 | 判断体育／科技／财经 | 生成摘要并比较两篇报道 |
| 客服问题 | 判断退款／物流／咨询 | 依据给定政策组织答复 |
| 学习提问 | 判断属于数学／编程等类别 | 解释反向传播并给出例子 |

LLM 也能输出分类标签，但需评估成本、稳定性和准确率；专用分类模型不能仅凭分类输出就自动写解释。生成质量还需检查事实、完整性和指令遵循，不能只看分类准确率。

## 4. 能做什么、不能保证什么？

能做：文本生成、摘要、翻译、信息提取、分类、代码辅助与基于给定材料的问答。
不能保证：事实全对、知识实时更新、复杂推理和计算始终正确；纯文本模型不能直接看图，实际查资料或操作软件还需相应工具。普通对话不会自动更新模型权重，上下文也不等于永久记忆。

Prompt 示例：“请只依据下面的课程通知，提取截止日期和提交材料，用两列表格输出；通知未说明的项目写‘未提供’。通知：……” 该约束有帮助，但仍需核对原文。
